# CMDM v2.30.1 — Mid Day Meal Data Entry & Reporting

One-file Windows setup for schools: XAMPP 8.2 + CMDM application with
built-in licensing. No technical setup needed.

## Install (5 minutes)
1. Download **CMDM_Setup_v2.30.1.exe** from the **[Releases](../../releases)** page above.
2. Double-click it (**Run as administrator**). Everything installs itself —
   no internet download needed. A desktop icon named **CMDM** appears.
3. The app opens showing your **Hardware ID**. Send it to us (see below).
4. Place the `Licence.json` file you receive inside
   `C:\xampp\htdocs\CMDM\`, reload with internet ON.
5. Create your school login on the setup page and start working.
   Use the desktop CMDM icon daily.
